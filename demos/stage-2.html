Demo 2 — Is the difference real, and does it matter?

Step 8. Look before you test

# The complete export: same sessions, logging fault fixed.
sessions <- read_csv("data/tidebreak_sessions.csv", show_col_types = FALSE)

boxplot(wrong_turns ~ build, data = sessions,
        main = "Wrong turns by build", ylab = "Wrong turns", col = "grey85")

Step 9. Another playtest, another answer

# Pretend we could only afford 15 sessions per build. Draw five such playtests.
set.seed(8015)
replicate(5, {
  a <- sample(sessions$wrong_turns[sessions$build == "A"], 15)
  b <- sample(sessions$wrong_turns[sessions$build == "B"], 15)
  mean(a) - mean(b)  # the difference this playtest would have reported
})
[1] 4.066667 3.733333 3.866667 3.466667 5.200000
# Now a thousand of them: the sampling distribution of the difference.
set.seed(8015)
diffs <- replicate(1000, {
  a <- sample(sessions$wrong_turns[sessions$build == "A"], 15)
  b <- sample(sessions$wrong_turns[sessions$build == "B"], 15)
  mean(a) - mean(b)
})
hist(diffs, breaks = 30, col = "grey85", border = "white",
     main = "1,000 playtests of 15 per build", xlab = "Difference in mean wrong turns")
sd(diffs)  # the standard error, seen directly
[1] 0.7831418

Question. Same builds, a thousand answers. Which one is “the” difference? Its spread is the standard error, which the t-test estimates from one sample. The students do not write this code; the picture is the point.

Step 10. Shuffle the labels: what does chance alone produce?

# If the build made no difference, its label would be arbitrary. Shuffle it.
gap <- function(y, g) mean(y[g == "A"]) - mean(y[g == "B"])
observed <- gap(sessions$wrong_turns, sessions$build)

set.seed(1)
shuffled <- replicate(10000, gap(sessions$wrong_turns, sample(sessions$build)))

hist(shuffled, breaks = 40, col = "grey85", border = "white",
     xlim = range(c(shuffled, observed)),
     main = "Gaps from shuffled build labels", xlab = "Difference (A - B)")
abline(v = observed, col = "firebrick", lwd = 3)
mean(abs(shuffled) >= abs(observed))  # the p-value: share of shuffles this extreme
[1] 0

Question. Not one shuffle in ten thousand got near the real gap. What does that say about “it was just the players we happened to get”? That share is what every p-value means.

result <- t.test(wrong_turns ~ build, data = sessions)

Step 12. Same players, both builds

paired <- read_csv("data/tidebreak_paired.csv", show_col_types = FALSE)

# Paired: each player compared with themselves, so player skill cancels out.
t.test(paired$wrong_turns_a, paired$wrong_turns_b, paired = TRUE)$conf.int
[1] 1.838014 3.695319
attr(,"conf.level")
[1] 0.95
# Same data, wrongly treated as two separate groups: a much wider interval.

[1] 1.180570 4.352763
attr(,"conf.level")
[1] 0.95
