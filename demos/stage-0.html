Stage 0 Demo

Our class, in numbers: a first look at real data, live

NoteGet the files
  • Demo code: stage-0-demo.qmd, every chunk on this page in one file you can run.
  • Data: none to download. The demo types its invented survey in; Step 1 shows how to load your own class’s CSV instead.

The data is a four-question class survey: height, MBTI personality type, favourite game genre and preferred drink. The 20 students below are invented, so that nobody’s answers end up on a public website, but they are messy in the same ways real answers are: a few blanks, a typo, an impossible value. To run the demo on your own class’s answers, see Step 1. Everything here uses the Stage 1 toolkit: tidyverse for handling the data, base R for the plots.

Demo — Our class, in numbers

Two problems. One student typed INFP-Mediator without the spaces, so R counts it as a different type. Another typed Cofee. Fix both inside mutate():

class <- class |>
  mutate(type     = substr(mbti_type, 1, 4),                       # keep "INFP"
         beverage = if_else(beverage == "Cofee", "Coffee", beverage))  # fix typo

class |> count(type, sort = TRUE)

substr(x, 1, 4) keeps characters 1 to 4. if_else(test, yes, no) gives yes where the test is TRUE and no where it is not, so only the typo changes.

Question. What goes in the cleaning log? (Two lines: INFP-Mediator recoded, Cofee recoded. No rows removed, but two students changed group.)

Step 4. A value that cannot be right

class |>
  summarise(min = min(height, na.rm = TRUE),
            max = max(height, na.rm = TRUE))
   min max
1 1.78 186
class |> filter(height < 100)   # nobody is under a metre tall
  id height       mbti_type                genre beverage type
1 15   1.78 ISTP - Virtuoso First-Person Shooter   Coffee ISTP

One student is 1.78 cm tall. Nobody is. They answered in metres, not centimetres, so the fix is to multiply by 100:

class <- class |>
  mutate(height = if_else(height < 3, height * 100, height))

class |> summarise(min = min(height, na.rm = TRUE),
                   max = max(height, na.rm = TRUE))
  min max
1 148 186

Question. Why fix 1.78 but keep 148? (1.78 is impossible and the meaning is clear: 178 cm. 148 cm is unusual but possible.)

Step 11. Pictures for a small class

With twenty students, the best pictures show every student, or every answer, rather than a distribution. First, the whole class’s personality profile: the share holding the first letter of each pair.

# One summary per letter pair: the share of the class with the first letter.
balance <- class |>
  summarise(E = mean(substr(type, 1, 1) == "E"),
            N = mean(substr(type, 2, 2) == "N"),
            T = mean(substr(type, 3, 3) == "T"),
            J = mean(substr(type, 4, 4) == "J"))
balance
     E   N   T    J
1 0.25 0.7 0.5 0.35
first  <- unlist(balance)           # the four shares as a plain vector
shares <- rbind(first, 1 - first)   # row 1: first letter, row 2: the other letter

par(mar = c(4, 12, 3, 1))   # room for the long labels on the left
bars <- barplot(shares, horiz = TRUE, las = 1, border = NA,
                col = c("steelblue", "grey85"),
                names.arg = c("Extravert / Introvert", "Intuitive / Sensing",
                              "Thinking / Feeling", "Judging / Perceiving"),
                main = "The class's personality profile", xlab = "Share of the class")
abline(v = 0.5, lty = 2)
text(first / 2, bars, c("E", "N", "T", "J"), col = "white", font = 2)
text(first + (1 - first) / 2, bars, c("I", "S", "F", "P"), font = 2)
par(mar = c(5, 4, 4, 2))

Question. Which pair is most even, which most lopsided? (Thinking / Feeling is even; Extravert / Introvert is one to three. Four pairs work because 16 types are too thin.)

Second, every student’s height, shortest to tallest, coloured by drink:

by_height <- class |>
  filter(!is.na(height)) |>   # a student with no height has no dot to draw
  arrange(height)

# A named vector works as a lookup: drink_col["Tea"] gives "darkseagreen".
drink_col <- c(Coffee = "tan4", Tea = "darkseagreen", Neither = "grey60")

dotchart(by_height$height, labels = paste("Student", by_height$id),
         pch = 19, cex = 0.8, col = drink_col[by_height$beverage],
         main = "Every student, shortest to tallest", xlab = "Height (cm)")
legend("bottomright", legend = names(drink_col), col = drink_col,
       pch = 19, bty = "n")

Question. What does this show that the histogram hid? (Every student, and the tall end is mostly coffee.) Everything you just did is Stage 1. Next: a playtest.
