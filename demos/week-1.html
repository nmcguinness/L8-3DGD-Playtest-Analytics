Week 1 Demo

Describing playtest data, live

The lecturer’s script for the two 15-minute demo slots in Week 1. Every chunk runs and shows its output. Step through it top to bottom; the bold headings are the places to pause. Base R plotting only this week.

Demo 1 — From values to a data frame

Step 1. A vector is a column

# Five players' deaths, typed in by hand. c() combines values into a vector.
deaths <- c(2, 0, 5, 3, 1)

deaths          # print it
[1] 2 0 5 3 1
length(deaths)  # how many players
[1] 5
deaths[3]       # the third player: square brackets pick by position
[1] 5
deaths > 2      # a condition gives one TRUE/FALSE per player
[1] FALSE FALSE  TRUE  TRUE FALSE
sum(deaths > 2) # TRUE counts as 1, so this is a count, not a total
[1] 2

Step 2. A missing value poisons the arithmetic

# The fourth player's log was lost. NA means "not recorded", not zero.
deaths <- c(2, 0, 5, NA, 1)

mean(deaths)               # NA: R will not guess
[1] NA
mean(deaths, na.rm = TRUE) # say out loud what you are leaving out
[1] 2

Step 6. The shape, the groups, the counts

hist(sessions$time_alive_s, breaks = 15,
     main = "Seconds alive", xlab = "Seconds", col = "grey85")
boxplot(session_minutes ~ build, data = sessions,
        main = "Session length by build", ylab = "Minutes", col = "grey85")
barplot(table(sessions$quit_reason),
        main = "How sessions ended", col = "grey85")
plot(sessions$deaths, sessions$score, pch = 19,
     main = "Deaths against score", xlab = "Deaths", ylab = "Score")

Pause here. Ask: which build loses players, and which plot told you?

Step 7. The frame-rate trap

frames <- read_csv("data/tidebreak_frame_times.csv", show_col_types = FALSE)

# Base R: one summary per build, one call per summary.
tapply(frames$ms, frames$build, mean)
       A        B 
16.99925 16.94679 
tapply(frames$ms, frames$build, quantile, 0.99)
      A       B 
19.4800 39.3708 
# Tidyverse: every summary per build in one table.
frames %>%
  group_by(build) %>%
  summarise(fps    = 1000 / mean(ms),
            median = median(ms),
            p99    = quantile(ms, 0.99))
# A tibble: 2 × 4
  build   fps median   p99
  <chr> <dbl>  <dbl> <dbl>
1 A      58.8   17.0  19.5
2 B      59.0   16.6  39.4

Finish here. Same frame rate, one build stutters. The mean could never have shown it.
