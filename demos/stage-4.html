Stage 4 Demo

Coding comments, triangulating, and a report that recomputes, live

NoteGet the files
  • Demo code: stage-4-demo.qmd, every chunk on this page in one file you can run.
  • Data: tidebreak_sessions.csv, tidebreak_survey.csv, tidebreak_sessions_raw.csv. Save them in a data/ folder next to the demo file.

Demo 1 — From evidence to a report that recomputes

Step 1. The survey arrives wide

library(readr)
library(dplyr)
library(ggplot2)
library(tidyr)

sessions <- read_csv("data/tidebreak_sessions.csv", show_col_types = FALSE)
survey <- read_csv("data/tidebreak_survey.csv", show_col_types = FALSE)
head(survey, 2)   # one column per question: the item is a column NAME
# A tibble: 2 × 9
  session_id controls_responsive objective_clear difficulty_fair level_navigable
  <chr>                    <dbl>           <dbl>           <dbl>           <dbl>
1 S001                         3               1               3               1
2 S002                         4               4               3               4
# ℹ 4 more variables: death_understood <dbl>, visual_style <dbl>,
#   would_play_again <dbl>, match_length <dbl>

Question. How would you get the mean of all eight items, by build, from this shape?

Step 2. Pivot it long

# Stack every column except the key: names into item, values into rating.
long <- survey |>
  pivot_longer(-session_id, names_to = "item", values_to = "rating")

dim(survey)
[1] 120   9
dim(long)   # 120 sessions x 8 items = 960 rows
[1] 960   3

Step 3. Every item at once, now that item is a column

long |>
  group_by(item) |>
  summarise(agree = mean(rating >= 4)) |>   # TRUE counts as 1
  arrange(agree)
# A tibble: 8 × 2
  item                agree
  <chr>               <dbl>

2 objective_clear     0.233
3 difficulty_fair     0.308
4 level_navigable     0.392
5 would_play_again    0.508
6 controls_responsive 0.758
7 match_length        0.758

Step 4. Code the comments, then ask whether the sources agree

coded <- sessions |>
  mutate(code = case_when(
    grepl("lost|circles|meant to go|objective", comment) ~ "Lost or unclear",
    grepl("route|exit|signposting", comment)             ~ "Found the way",
    grepl("Died|hard", comment)                          ~ "Difficulty",
    TRUE                                                 ~ "General"
  ))

coded |> count(code, build)                      # against the telemetry...
# A tibble: 8 × 3
  code            build     n
  <chr>           <chr> <int>
1 Difficulty      A        19
2 Difficulty      B        16
3 Found the way   A        12
4 Found the way   B         9
5 General         A         6
6 General         B         4
7 Lost or unclear A        23
8 Lost or unclear B        31
coded |> count(code, enjoyed = enjoyment >= 5)   # ...and against enjoyment
# A tibble: 4 × 3
  code            enjoyed     n
  <chr>           <lgl>   <int>
1 Difficulty      FALSE      35
2 Found the way   TRUE       21
3 General         TRUE       10
4 Lost or unclear FALSE      54

Question. Build B took far fewer wrong turns, yet more of its players wrote that they were lost. Which evidence do we trust for what? Where does this go in the report: Results, Discussion, or both?

Step 5. The report skeleton

The report is a .qmd file: the eight assessment headings, a hidden setup chunk, and numbers written as inline R.

---
title: "Tidebreak Build B: Playtest Report"
---

```{r}
#| echo: false
sessions <- readr::read_csv("data/tidebreak_sessions.csv", show_col_types = FALSE)
```

## Executive Summary
## Introduction
## Methodology

We analysed `r nrow(sessions)` sessions.

## Results
## Discussion
## Conclusion
## References
## Appendices

Step 6. Watch the inline numbers recompute

# One sentence of the Methodology, with its numbers as inline R.
part2 <- paste(
  "We analysed `r nrow(sessions)` sessions. Build A's median session lasted",
  "`r median(sessions$session_minutes[sessions$build == 'A'], na.rm = TRUE)` minutes."
)

# render_text() does to this sentence what quarto render does to the report.
render_text(part2)   # against the full data...

We analysed 120 sessions. Build A's median session lasted 23.25 minutes.
# ...then against Stage 2's raw export with incomplete rows dropped.
raw <- read_csv("data/tidebreak_sessions_raw.csv", show_col_types = FALSE)
sessions <- raw[!duplicated(raw), ]
sessions <- sessions[complete.cases(sessions), ]

render_text(part2)

We analysed 109 sessions. Build A's median session lasted 25.5 minutes.

Question. Which of those two sentences would have gone into the report if the numbers were typed by hand? Then: open your own report.qmd.
