One page to keep open while you work

A lookup sheet, not a tutorial. Everything here appears in the notes or labs; this page exists so you are not scrolling back through the notes to remember an argument name. Rows marked (recognise) are older ways of doing the same job: you will see them in code online, but you do not need to write them. The ideas behind it are taught in R from First Principles.

Values and vectors

Task Code
Build a vector deaths <- c(2, 0, 5, 3, 1)
How many values length(deaths)
What type class(deaths)
Repeat a value rep("A", 3)
Count values meeting a condition sum(deaths > 2) (TRUE counts as 1)
Proportion meeting a condition mean(deaths > 2)
The distinct values unique(d$cohort)
Distance to zero abs(-3)
Differences between neighbours diff(c(2, 5, 9))
Vectors side by side as a table data.frame(player = c("P1", "P2"), deaths = c(2, 0))

Task Code
Load the packages library(readr), library(dplyr)
Check a file is where you think file.exists("data/file.csv")

Look at size, columns and types glimpse(d)
How many rows nrow(d)
Structure, first rows (recognise) str(d), head(d, 5)

Getting at parts of a data frame

Task Code
One column as a vector d$score
Several columns (Stage 2) d \|> select(score, deaths)
Rows meeting a condition (Stage 2) d \|> filter(score > 1500)
The same with brackets (recognise) d[["score"]], d[d$score > 1500, c("score", "deaths")]

Describing one variable

Task Code
Centre mean(x), median(x)
Spread sd(x), IQR(x), range(x)
Quartiles quantile(x)
A specific percentile quantile(x, 0.99)
Several summaries in one table d \|> summarise(n = n(), median = median(score), iqr = IQR(score))
Count a category d \|> count(cohort)
Biggest first, with proportions d \|> count(quit_reason, sort = TRUE) \|> mutate(prop = n / sum(n))
Count every combination of two d \|> count(build, quit_reason)
One proportion mean(d$quit_reason == "Frustrated")
Ignore missing values add na.rm = TRUE
Counts and summaries (recognise) summary(x), table(d$cohort), prop.table(table(...))

Describing by group

Task Code
Summaries per group d \|> group_by(cohort) \|> summarise(n = n(), med = median(score))
A proportion per group d \|> group_by(build) \|> summarise(frustrated = mean(quit_reason == "Frustrated"))
The same (recognise) tapply(d$score, d$cohort, median), aggregate(score ~ cohort, data = d, FUN = median)

Cleaning

Task Code
Which values are missing is.na(d$deaths)
Missing values in every column colSums(is.na(d))
Rows with a blank in a column d \|> filter(is.na(session_minutes))
Remove repeated rows d <- d \|> distinct()
Keys that appear more than once d \|> count(session_id) \|> filter(n > 1)
Strip spaces and fix case d \|> mutate(cohort = tolower(trimws(cohort)))
Fix the order of categories d \|> mutate(cohort = factor(cohort, levels = c("novice", "regular", "veteran")))
Check a fix d \|> count(cohort), before and after
Text to numbers as.numeric(x) (unreadable values become NA)
Does text contain a word grepl("lost\|circles", d$comment)
Are two objects exactly the same identical(a, b)
The same jobs (recognise) duplicated(d), d[!duplicated(d), ], complete.cases(d), na.omit(d)

Record every row you drop, why, and the n before and after. Cleaning is analysis.

Transforming with dplyr

Load with library(dplyr). Each verb takes a data frame and returns one.

Task Code
Pass a result into the next function d \|> filter(build == "A")
Keep rows d \|> filter(build == "A", score > 1500)
Keep rows matching either condition d \|> filter(is.na(deaths) \| is.na(session_minutes))
Keep columns d \|> select(session_id, build, score)
Add or change a column d \|> mutate(kd = kills / deaths)
Sort rows d \|> arrange(score); largest first arrange(desc(score))
One row of results per group d \|> group_by(build) \|> summarise(n = n(), mean_score = mean(score))
One column as a vector, in a pipe d \|> pull(score)
Choose a value by condition case_when(score > 1500 ~ "high", TRUE ~ "other"), inside mutate()

%>% is the older pipe from the tidyverse and does the same job as |>.

Relationships and tests

Task Code
Confidence interval for one mean t.test(x)$conf.int
Compare two groups of different players t.test(wrong_turns ~ build, data = d)
Compare the same players twice t.test(p$before, p$after, paired = TRUE)
Keep the result and pull out parts res <- t.test(...), then res$estimate, res$conf.int, res$p.value
Width of an interval diff(res$conf.int)
Compare two proportions prop.test(c(20, 5), c(60, 60)): counts of “yes”, then group sizes
Correlation, −1 to +1 (Stage 3) cor(d$awareness, d$score)
Shuffle labels for a permutation test (recognise) replicate(10000, gap(y, sample(group)))
Draw a random sample (recognise) sample(x, 30); with replacement: sample(x, replace = TRUE)
Check normality (Going further) qqnorm(x); qqline(x)
Fit a straight line (Going further) fit <- lm(score ~ awareness, data = d), then coef(fit), summary(fit)$r.squared

Errors you will meet

Message What it means
could not find function "..." Missing library() call, or a typo in the name
object '...' not found The variable does not exist yet, or R was restarted
$ operator is invalid for atomic vectors You used $ on a vector, not a data frame
undefined columns selected A column name is misspelled or wrongly capitalised
argument "x" is missing, with no default A function was called with no argument
Console shows + not > R is waiting for you to close a bracket or quote. Press Esc
NA where you expected a number Missing values. Decide what to do about them, then use na.rm = TRUE
